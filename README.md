# Sistem Informasi Pendaftaran BMT-LPK

Aplikasi web untuk mengelola proses pendaftaran anggota serta pembiayaan untuk kerjasama BMT-LPK.  
Dibangun menggunakan CodeIgniter 4.

---

## 🚀 Fitur Utama
- Pendaftaran anggota baru
- Pengelolaan data pembiayaan
- Pengelolaan berkas
- Manajemen user dan role
- Export data (Excel/PDF)
- Dashboard monitoring

---

## 🛠️ Penggunaan
- **Backend** : PHP (CodeIgniter 4)
- **Frontend** : HTML, CSS, JS (Bootstrap)
- **Database** : MySQL
